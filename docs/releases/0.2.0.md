# Noise 0.2.0 · Windows beta

Adds Windows 11 x64 support with a notification-area panel, multi-app selection,
48 kHz local audio filtering, DPDFNet/DeepFilterNet3/RNNoise, automatic Main
speaker mode, adjustable reduction, and speech-aware voice leveling. The shared
C++ DSP is also used by the existing native macOS app.

Install using the per-user setup EXE or extract the portable ZIP and run Noise.exe.
Both include the .NET runtime, native libraries, and models. The installer is
unsigned. This private release requires access to the repository.

**Routing prerequisite:** install signed virtual audio cable devices separately.
Incoming apps must be routed to an isolation cable in Windows Volume mixer;
simultaneous incoming and microphone filtering requires two independent cables.
Follow [the Windows setup guide](../WINDOWS.md). Restore app outputs to Default
before quitting Noise. No driver or audio-default changes are made by the installer.

The macOS package remains available in release 0.1.0. This Windows release does
not replace or rebuild that package.
