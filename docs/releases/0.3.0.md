# Noise 0.3.0 · Linux beta

Adds Linux x64 support using PulseAudio or PipeWire-Pulse, automatic multi-app
routing, a virtual microphone, current-output following, and recovery of routes
after an unexpected exit. Filters and voice leveling are shared with macOS and Windows.

Install the Debian package on Ubuntu 24.04+ or use the portable archive on a
compatible system with glibc 2.39+ and its dependencies. .NET and models are included.

See [Linux setup](https://github.com/mvs2403/Noise/blob/v0.3.0/docs/LINUX.md).
Window picking needs X11 and xdotool; Wayland supports application checkboxes.
Tray behavior depends on the desktop's indicator host. Main speaker mode remains
experimental. These are unsigned private betas.

This release also includes refreshed Windows x64 packages with a compact two-tab
control panel and bundled setup documentation. Windows still requires separately
installed virtual audio cables; see [Windows setup](https://github.com/mvs2403/Noise/blob/v0.3.0/docs/WINDOWS.md).

macOS 0.1.0 remains available in its release.
