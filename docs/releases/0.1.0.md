# Noise 0.1.0 · Private beta

Noise reduces background noise in incoming app audio and your microphone using
local processing on Apple Silicon Macs running macOS 14.2 or later.

## Install

Download **Noise-0.1.0-apple-silicon.dmg**, open it, and drag **Noise.app** into
**Applications**. Eject the image, open Noise, and use its waveform menu-bar icon.
No Xcode, Rust, Python, or separate model downloads are needed to use the app.
The ZIP contains the same app as an alternative.

**This beta is ad hoc signed and is not notarized.** macOS may block first launch.
After trying to open it, follow Apple's per-app
[Open Anyway instructions](https://support.apple.com/102445), if available.

Incoming filtering works immediately after macOS audio-recording permission.
Outgoing filtering needs the optional **Noise Microphone** driver: install it
from Noise Settings before a call, then select it in Teams/Zoom/etc. Installation
requires administrator access and briefly interrupts audio.

## Included

- Speaker and Microphone menu-bar tabs, independent cancellation and leveling.
- Full-width app selection, multi-app checkboxes, Use current app, and window picking.
- Live noise-reduction sliders while cancellation is enabled.
- Follow Mac output by default; explicit output overrides remain available.
- DPDFNet, DeepFilterNet3 and RNNoise, with DPDFNet as the default.
- All voices and experimental automatic Main speaker focus using Hush.
- Background operation without a Dock icon.
- All runtimes/models, optional microphone driver, notices and licenses bundled.

## Validation and limits

28 automated audio tests pass. The optimized app's architecture, deployment
targets, signatures, bundled dependencies, and all four engine-loading/streaming
checks pass. Menu controls were verified using an isolated native preview.

Main speaker can soften the intended voice or retain competing speakers. Voices
at similar levels and overlapping speech remain difficult. Processing is mono;
this release is not a general music enhancement tool. Live Teams routing,
administrator driver installation, and switching hardware outputs during a call
still need hands-on validation.

The matching source archive includes Noise Microphone's GPL source and build
scripts. `release-manifest.json` records the exact commit; `SHA256SUMS.txt`
verifies the release files. Repository access is required to download this private release.
